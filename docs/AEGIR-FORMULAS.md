# 阿戈尔 v1.3 数值与叠层公式

核对日期：2026-10-10，玩法基线提交：`f60a620`。本文按该版本的生成参数和实际处理函数记录【阿戈尔】`egirShip`，与 [全部盟约公式](BOND-FORMULAS.md)、[全部叠层来源](BOND-LAYER-SOURCES.md) 配套。

当前人数档位为 **3 / 5**。三人启用生命加成与开战吞噬；五人再启用三次首次击倒复活和吞噬链攻击传递。六人继续使用五人档，没有独立六人灼烧。部分特质描述仍保留“盟约灼烧击杀也计入”的旧字样，v1.3 的阿戈尔没有灼烧处理器，本文以实际执行为准。

## 层数与属性口径

`L` 为本玩家阿戈尔当前层数，整局保留、封顶 999；`N` 为有效盟约人数，同一基础干员的普通与精锐合计一人。调和按主文规则补人数并享受已激活核心盟约效果。下文属性倍率只表示阿戈尔这一项；装备、技能、其他盟约的百分比先相加，不能把每项倍率直接连乘。标准模拟禁用阿戈尔，以下战斗效果在该模式下不生效。

普通作战允许战斗特质叠层，联防、最终攻势、隐秘核心默认不允许战斗内叠层，但仍使用已有层数计算属性、吞噬与传递。获得时等明确无需激活的休整期来源可向未激活盟约加层；未激活时不享受按层增益。

## 三人：生命加成与开战吞噬

成员生命百分比加成来自 `base_max_hp=0.35`、`max_hp_per_stack=0.01`：

```text
生命加成 bHP(L) = 0.35 + 0.01L
仅计阿戈尔的最大生命倍率 MHP(L) = 1.35 + 0.01L
```

生命加成随战斗层数刷新。吞噬的攻击力与阻挡数在开战标记时计算：设 `F(u)` 为干员 `u` 标记的吞噬目标集合，`At基础`、`Bt基础` 分别为目标的基础攻击力与基础阻挡数，`L开战` 为吞噬计算时的阿戈尔层数。

```text
吞噬攻击力系数 r(L开战) = 0.20 + 0.006L开战
攻击力最终加算 ΔA吞噬(u) = r(L开战) × Σt∈F(u) At基础
阻挡数加算 ΔB吞噬(u) = Σt∈F(u) Bt基础
吞噬直接产生的阿戈尔层数 ΔL吞噬 = 0

干员当前攻击力 = [(自身基础攻击力 + Σ攻击固定加算)
                  × max(0, 1 + Σ攻击百分比)
                  + Σ其他攻击最终加算 + ΔA吞噬] × Π独立攻击力倍率
```

吞噬取目标的基础值，不取目标开技能或装备后的当前攻击力、阻挡数。`ΔA吞噬` 在百分比项之后加入，因此不再吃自身的攻击百分比；若另有独立攻击力倍率，仍按完整属性公式处理。后续叠层只刷新生命等实时按层效果，不重新计算这次吞噬得到的攻击力。吞噬增益保留至本场结束，死亡、再部署不清掉，也不会重新吞噬。

例如自身基础攻击力 1000、其他攻击百分比合计 +100%，吞噬目标基础攻击力总和 1200，在 100 层时 `r=0.8`，且没有其他固定加算、最终加算或独立倍率，则当前攻击力为 `1000×2+1200×0.8=2960`。若目标基础阻挡数之和为 3，则另外获得 +3 阻挡，与层数和克莱门莎策略无关。

开战时按阿戈尔成员的棋盘位置排序放置标记，查找身前一格干员；目标本身属于阿戈尔时继续沿其身前延伸，否则该目标成为链末。按来源去重、避开循环及互相吞噬；召唤物、装置、空格不作为吞噬目标。共享战场可吞噬队友干员。先为全部标记计算攻击、阻挡，再按标记顺序处理生命流失，因此增益集合与最后实际执行的吞噬次数可能不同。

每个实际执行的吞噬标记造成物理生命流失：

```text
流失基数 V = 5000
实际流失 = max(5000 - max(0, 目标当前防御力), 5000×0.05)
         = max(5000 - max(0, 目标当前防御力), 250)
```

这里通过 `mitigate` 计算防御衰减后调用 `loseHp`，不经过普通伤害的护盾、闪避、造成/承受伤害倍率。同一目标被多名来源标记时，可能承受多次流失；目标首次被击倒后，尚未执行的标记取消，立刻复活也不会再执行旧标记。标记者先被击倒不取消其自身已放出的标记。联防开场已倒地干员可参与标记及攻击、阻挡继承，但针对该倒地目标的标记不会执行流失或计入实际吞噬。

## 五人：复活与攻击传递

每场战斗中，按实际击倒顺序，前 3 名首次被击倒的阿戈尔干员各有一次立即复活；每名干员最多占用一次名额，总数不随 `L` 增长。开战吞噬造成的击倒也占名额。阻止实际击倒的保命效果、联防开场强制离场不占名额。复活满生命、重置技力并执行部署效果；普通作战、联防、领袖战分别计算本场名额。

攻击传递只在自身攻击范围及自身阻挡均没有可攻击目标时启用：从开战吞噬链中寻找仍在场的干员，将其正在阻挡的、可被本体攻击的**非远程敌人**纳入候选。敌人类型按 `applyWay !== 'RANGED'` 判定，仍经过本体对飞行、隐匿、睡眠等目标的正常可攻击检查。被选作传递终点的干员必须存活且确实阻挡该敌人，单纯处在其攻击范围内不够；这个终点可以是链中的任一有效节点。

设 `h` 为本体到该阻挡干员的**开战原始跳数**。同一敌人有多条可用路径时取最小 `h`：

```text
传递倍率 m(h) = 0.8^h
传递攻击伤害 = 同一攻击经防御/法抗及普通伤害倍率计算后的数值 × 0.8^h
```

倍率写入攻击的 `damageMul`，在防御、法抗衰减之后乘算，之后仍有领袖限伤、护盾等结算。不能先把攻击力乘 `0.8^h` 再扣防御；护盾或限伤存在时，最终扣血也不能简单照搬倍率。普通物理、法术攻击保留原伤害类型，不自动转为真伤。

| 原始跳数 h | 伤害保留比例 |
|---:|---:|
| 1 | 80% |
| 2 | 64% |
| 3 | 51.2% |
| 4 | 40.96% |

中间节点死亡不切断链，也不减少跳数；原来两跳的路径仍为 64%。末端阻挡者死亡或不再阻挡时失去该目标，该干员再部署并重新阻挡后可恢复原路径。末端移动不重算链长。传递继续使用攻击者自己的攻击力、攻击间隔、所选技能、目标数、弹药与击杀归属，不额外增加一次攻击或定时伤害。攻击者有本地目标时优先普通攻击，伤害不作传递衰减；远程弹道的传递倍率在出手时记录。

## 干员产生层数的公式

以下累计式以目标始终激活、普通作战、没有额外层数钩子或重触发为前提，最后仍受 999 层封顶。每场限额按干员特质实例、目标盟约分别计算，多个副本不共享限额。`K` 是归属该干员的合格击杀数；传递攻击造成的击杀归属发起攻击者，可触发其击杀特质。

| 干员与触发 | 目标 | 普通公式 | 精锐公式 |
|---|---|---|---|
| 斯卡蒂：击杀敌人 | 自身每个已激活所属盟约，原生为阿戈尔、坚守、突袭 | `min(20, 2K)` | `min(30, 4K)` |
| 幽灵鲨：获得时 | 阿戈尔，无需激活 | 每次 `+2` | 每次 `+4` |
| 幽灵鲨：每击杀 5 名敌人 | 仅已激活阿戈尔 | `min(10, floor(K/5))` | `min(20, 2floor(K/5))` |
| 归溟幽灵鲨：获得时 | 阿戈尔、不屈，无需激活 | 阿戈尔 `+4`；不屈 `+6` | 阿戈尔 `+8`；不屈 `+12` |
| 归溟幽灵鲨：切换为替身 | 分别检查阿戈尔、不屈是否激活 | 阿戈尔 `Σqj`；不屈 `2Σqj` | 阿戈尔 `2Σqj`；不屈 `4Σqj` |
| 海霓：首次击倒敌人或我方干员 | 已激活阿戈尔、奥术，逐盟约计算 | `min(3, 3K)` | `min(6, 6K)` |

归溟幽灵鲨第 `j` 次**进入替身**时，`qj=floor(Rj/2)`，`Rj` 为该时刻同一行、同一玩家仍在场的干员数，含自身，不含召唤物、离场干员或队友。返回本体、单纯击杀敌人不触发该公式。此特质没有另外设置每场叠层上限；阿戈尔与不屈各自检查激活，不能因其中一个未激活而忽略另一个。

例如同排干员数依次为 1、3、4，则 `q` 为 0、1、2，三次进入替身总共使普通归鲨获得阿戈尔 +3、不屈 +6；精锐为 +6/+12。幽灵鲨击杀 4、5、50、60 人时，普通分别增加 0、1、10、10 层，精锐分别为 0、2、20、20 层。

斯卡蒂、幽灵鲨的吞噬友军击杀不计入其敌人击杀；海霓明确允许我方干员，实际由她击倒友军时仍可触发自身特质，所以“吞噬直接叠层为 0”不等于“吞噬事件不会触发任何干员特质”。获得时特质在投资人激活时触发两次，投资人达到 100 层时触发三次；魔王等额外层数需另按 [统一叠层结算](BOND-LAYER-SOURCES.md) 计算。

对应参数为 `garrison_38_a/b`、`garrison_46_a/b`、`garrison_40_a/b`、`garrison_131_a/b`，以及 `garrison_custom_specter_gain_a/b`、`garrison_custom_specter2_gain_a/b`、`garrison_custom_specter2_swap_indom_a/b`。

## 干员读取阿戈尔层数的增益

下表为干员自身特质，不能加到全部阿戈尔成员身上。只读取已激活阿戈尔层数；精锐倍率取对应 `_b` 参数。

| 干员 | 普通增益 | 精锐增益 | 特质组 |
|---|---|---|---|
| 水月 | 攻击百分比 `+0.01floor(L/3)` | `+0.02floor(L/3)` | `garrison_07` |
| 乌尔比安 | 攻击百分比 `+0.01floor(L/2)` | `+0.02floor(L/2)` | `garrison_12` |
| 浊心斯卡蒂 | 每秒生命回复 `+50floor(L/10)`；自然技力回复 `+0.15floor(L/10)/秒` | 分别 `+100floor(L/10)`、`+0.30floor(L/10)/秒` | `garrison_84` |

水月、乌尔比安的攻击百分比先加入攻击百分比总和，再计算吞噬最终加算。例如 100 层时水月普通 +33%、精锐 +66%，乌尔比安普通 +50%、精锐 +100%；不把吞噬攻击最终加算再乘这些百分比。哈洛德、迷迭香等读取多个已激活盟约层数之和的特质也可读到阿戈尔，完整公式见叠层来源文档。

## 克莱门莎策略：吞噬计数与下回合招募

当前策略每累计实际吞噬 **10 名干员（不限盟约）**，下回合获得 1 名不高于领取时调度中心等级的随机阿戈尔干员。该计数与 `L` 独立，不再按击倒数奖励，也不再以策略开启吞噬阻挡加成。

`c` 为此前保留的吞噬余数，`n` 为本次结算的自身作战与本玩家联防吞噬计数之和，`p` 为待领取奖励数：

```text
total = c + n
本次新增奖励数 earned = floor(total / 10)
新余数 c新 = total mod 10
新待领取数 p新 = p + earned
首次产生待领取奖励的到期回合 = 当前回合 + 1
领取候选条件：属于阿戈尔，干员等阶 ≤ 领取时调度中心等级
```

吞噬计数只接收本玩家吞噬者实际执行的吞噬事件，同一玩家同场对同一目标去重，不要求目标被流失击倒，不要求目标属于阿戈尔。只放置标记而未执行不计；不同场战斗重新去重。即使联防禁止战斗特质叠层，策略吞噬计数仍可累计。

例如原余数为 9、本次普通作战加联防合计吞噬 12 人，则 `total=21`，新增两份奖励并保留余数 1。到期时逐名发放；候选池为空或无法发放时，待领取数保留，后续回合继续尝试。新招募干员照常触发获得时特质，可以间接产生盟约层数；策略计数自身不直接加层。
