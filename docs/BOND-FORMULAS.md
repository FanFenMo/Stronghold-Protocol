# 盟约数值计算与公式汇总

本文记录本项目当前源码实际执行的公式，核对日期为 **2026-10-10**，基线提交为 `f60a620`。已整理 **23 个盟约**及玛恩纳新增技力回复特质；阿戈尔按当前 v1.3 实现记录，详见 [阿戈尔数值与叠层公式](AEGIR-FORMULAS.md)。历史调研中的原版数值不作为本文件的计算依据。

盟约本身如何随层数增强见本文；干员、策略、装备与机变如何产生层数，以及干员自己的按层增益，见 [盟约叠层来源与干员公式](BOND-LAYER-SOURCES.md)。

## 计算口径

`L` 表示**当前玩家、当前盟约**的层数，不是全部盟约层数总和。除特别说明外，公式只在盟约激活时生效。`N` 是当前有效盟约人数，通常按不同干员的基础 ID 去重，同一干员的普通与精锐合计 1 人。`A` 是伤害发生时的当前攻击力，`H` 是最大生命值，`floor(x)` 向下取整，`clamp(x,a,b)` 把数值限制在 `[a,b]`。

层数整局保留，每个盟约独立封顶 999。未激活时仍可存储层数；只有明确允许“无需激活”的来源能继续向未激活盟约加层。战斗内叠层在普通作战中开启，联防、最终攻势、隐秘核心默认关闭；这些阶段依然使用已有层数计算增益。

表中的“属性倍率”是**只考虑这一项加成时**的结果。项目把盟约、装备、策略、技能的攻击力、防御力、生命值百分比加成先相加，不能把这些表中倍率互相连乘。例如炎提供 `+50%`、装备提供 `+30%`，合计倍率为 `1+0.50+0.30=1.80`。

```text
攻击力 = [(基础攻击力 + Σ攻击力固定加算) × max(0, 1 + Σ攻击力百分比)
          + Σ攻击力最终加算] × Π独立攻击力倍率
最大生命值 = (基础最大生命值 + Σ生命固定加算) × max(0, 1 + Σ生命百分比) × Π独立生命倍率
防御力 = (基础防御力 + Σ防御固定加算) × max(0, 1 + Σ防御百分比) × Π独立防御倍率
攻击速度 = clamp(基础攻击速度 + Σ攻击速度加成, 20, 600)
攻击间隔 = 基础攻击间隔 × max(0.1, 1 + Σ攻击间隔百分比) × 100 / 攻击速度
```

攻击力与防御力最终不低于 0，最大生命值最终不低于 1。“最终加算”位于百分比计算之后，不会被前面的攻击力百分比重复放大。伤害倍率则进入伤害结算管线；以下伤害公式给出送入管线的原始数值，最终扣血还会受到伤害增减、护盾、无敌和领袖限伤等规则影响。真伤跳过防御与法术抗性，不意味着跳过所有伤害结算规则。

人数与受益范围还有三个例外：远见、奇迹、投资人计算场上与整备区的不同干员，临时整备区不计；助力高档按“不同姓名或精锐状态”计数；绝技计算场上所有精锐干员数量，同名精锐可重复计入。调和对已有真实成员的核心盟约人数额外 `+1`，自身享受已激活核心盟约的效果。

标准模拟禁用拉特兰、阿戈尔、卡西米尔、灵巧、奥术、奇迹、投资人、突袭、独行、绝技，这些盟约的公式在该模式下不生效。

## 核心盟约

### 炎 `yanShip`：3 / 6 / 9 人

成员攻击力百分比加成：

```text
攻击力加成 b(L) = 0.23 + 0.009L
单项攻击力倍率 M(L) = 1.23 + 0.009L
```

6 人时在开战时召唤 1 名炎佑，9 人时召唤 2 名。每名炎佑按开战时**真实炎干员**的当前攻击力与最大生命值之和继承，调和干员只有本身也属于炎时才计入总和：

```text
炎佑攻击力 = (600 + 0.30 × Σ炎干员当前攻击力) × (N ≥ 9 ? 1.5 : 1)
炎佑最大生命值 = 12000 + 0.30 × Σ炎干员当前最大生命值
九炎时炎佑承受伤害倍率 = 1 - 0.90 = 0.10
```

炎佑继承在召唤时取值，不会持续跟着后续 `L` 更新；九炎的 `×1.5` 只作用于炎佑。实现：`core.js / installYan`，`tokens.js / spawnYanyou`。

### 萨尔贡 `sargonShip`：3 / 6 人

任一成员开启技能，场上成员各获得一层独立持续的技能触发增益。这里的 `s` 是尚未过期的**增益层数**，不是盟约层数 `L`：

```text
每次增益持续时间 T(L) = 5 + 0.22L 秒
0 ≤ s ≤ 25
攻击速度加成 = 12s
六萨尔贡时攻击力加成 = 0.12s，单项攻击力倍率 = 1 + 0.12s
```

层数提高的是持续时间，使多次技能更容易重叠；不会直接提高单次 `+12` 攻速或 `+12%` 攻击力。选娜仁图亚策略时，六人效果改为向周围 8 格干员借出施法者不高于 V 阶的装备效果，持续 `60+0L=60` 秒，取代六人攻击力叠加；攻速与 `5+0.22L` 秒仍保留。实现：`core.js / installSargon`、`lendAround`。

### 维多利亚 `victoriaShip`：3 / 6 人

```text
携带至少一件装备的成员：造成伤害倍率 M(L) = 1.25 + 0.008L
累计重锤奖励件数 Q(L) = floor(L / 25)
本次补发件数 = Q(L) - 已支付里程碑数
六维多利亚攻击力加成 = 0.50n普通 + (0.50+0.30)n精锐装备
                         = 0.50n普通 + 0.80n精锐装备
```

未装备成员不获得该伤害倍率。重锤里程碑整局只支付一次；未激活时欠下的里程碑可在后续激活时补发。六人装备攻击力加成不再额外乘 `L`。实现：`core.js / installVictoria`、`payHammers`。

### 谢拉格 `kjeragShip`：3 / 6 人

```text
对未寒冷、未冻结敌人：造成伤害倍率 = 1.25
对寒冷或冻结敌人：造成伤害倍率 M(L) = 1.35 + 0.01L
六谢拉格寒风周期 = 25 秒，第一阵在 25 秒后
每次寒风施加的寒冷持续时间 T(L) = 20 + 0.10L 秒
```

寒冷倍率替代普通 `1.25`，二者不连乘；同一敌人寒冷、冻结也不重复计算两次。寒风覆盖共享战场的敌人，持续时间在每次起风时读取当前 `L`。实现：`core.js / installKjerag`，`devices.js / kjeragColdWind`。

### 拉特兰 `lateranoShip`：3 / 6 人

```text
技能弹药数 = floor(B × (1.05 + 0.015L))
六拉特兰攻击力加成 = min(2.00, 0.04C)
六人单项攻击力倍率 = 1 + min(2.00, 0.04C)
```

`B` 为成员弹药技能开启时、干员技能与天赋已处理后的弹药数；`C` 为本场战斗所有成员累计消耗弹药数。每消耗一发，全体成员获得 `+4%` 攻击力，最多 `+200%`，50 发达到上限；这个攻击力效果与 `L` 无关。弹药倍率只作用于弹药技能。实现：`core.js / installLaterano`。

### 阿戈尔 `egirShip`：3 / 5 人

```text
成员生命加成 bHP(L) = 0.35 + 0.01L，单项生命倍率 = 1.35 + 0.01L
开战吞噬攻击继承系数 r(L) = 0.50 + 0.005L
吞噬攻击力最终加算 = r(L开战) × Σ标记目标基础攻击力
吞噬阻挡加算 = Σ标记目标基础阻挡数
每个实际执行标记的物理生命流失 = max(5000-max(0,目标当前防御力),250)
吞噬直接增加盟约层数 = 0
五人攻击传递倍率 m(h) = 0.8^h，h 为开战原始链路跳数
```

吞噬攻击放在自身攻击百分比之后加算，后续叠层不重算已吞噬攻击；生命加成随层数刷新。目标为身前干员，本身属于阿戈尔时继续延伸；先计算全部标记的属性继承，再执行流失，目标击倒后未执行的标记取消。阻挡继承不随 `L` 或策略变化。

五人时，每场前 3 名首次实际被击倒的成员各复活一次，包括吞噬击倒；自身无本地可攻击目标时，可攻击原吞噬链中存活干员正在阻挡的非远程敌人。传递伤害在防御/法抗衰减后乘 `0.8^h`，保留自身攻击类型、技能与击杀归属。中间节点死亡不切断或缩短路径；原两跳仍为 64%。六人使用五人档，没有独立灼烧。

克莱门莎策略按实际吞噬计数：`新增奖励=floor((旧余数+本次吞噬数)/10)`，新余数取模 10，下回合奖励对应数量的随机阿戈尔，等阶不高于领取时调度中心等级。吞噬目标不限盟约，同一玩家同场同一目标去重，策略本身不直接加层。双鲨已改为获得、每五次击杀或切替身叠层，完整普通/精锐公式、复算示例和源码入口见 [阿戈尔专篇](AEGIR-FORMULAS.md)。实现：`core.js / devour / installEgir`、`aegirRelay.js / installAegirRelay`。

### 叙拉古 `siracusaShip`：3 / 6 人

```text
成员每次部署后的攻速加成 = 25 + 0.80L
攻速增益持续时间 T(L) = 32 + 0.40L 秒
六叙拉古隐匿时间 = T(L)，隐匿结束后额外允许触发 10 秒
附加原始真伤 D(L) = 5000 + 50L
第 k 次有效尝试触发概率 p(k) = min(1, 0.0013861777203907307k)
成功造成附加伤害后 k 清零；恐惧持续 3 秒
```

攻速与持续时间在部署时取当前 `L`；附加真伤在触发时读取当前 `L`。保底计数由同一玩家的成员共享，采用上游 PRD，概率为 `min(1, 0.0013861777203907307 × n)`，长期平均为 3%；触发后重置计数，概率不随 `L` 增长。普通伤害实例可尝试触发，普通攻击与符合条件的技能都能触发；持续、溅射、附加、元素、无来源伤害与生命流失不尝试。实现：`core.js / installSiracusa`、`siracusaRolls`。

### 卡西米尔 `kazimierzShip`：3 / 6 人

```text
成员攻击力加成 b(L,d) = min(0.20d, 0.50 + 0.01L)
单项攻击力倍率 = 1 + b(L,d)
六人、正在阻挡的成员：每 2 秒，半径 0.8 格内原始真伤 = 1.20A，眩晕 0.1 秒
六人、未阻挡的成员：每次攻击附加原始真伤 = 0.30A
```

`d` 为本场本玩家的**所有干员**累计部署次数，初次部署与再部署都计入；不是只有卡西米尔成员部署才叠。`L` 提高攻击力加成上限，不改变每次 `+20%` 或六人两种真伤系数。实现：`core.js / installKazimierz`。

## 附加盟约

### 精准 `preciShip`：2 / 3 人

```text
攻击力加成 b(L) = 0.10 + 0.012L
单项攻击力倍率 M(L) = 1.10 + 0.012L
三人时忽略目标防御比例 = 30%，忽略目标法抗比例 = 30%
```

两人档只作用于成员；三人档扩展到本玩家所有远程位置干员，成员也保留加成。这是忽略防御、法抗，不能解释为固定增加 30% 伤害。实现：`addon/battle.js / applyPassives`。

### 迅捷 `swiftShip`：2 人

```text
技能结束触发概率 p(L) = clamp(0.20 + 0.0035L, 0, 1)
成员成功触发获得 12 技力
L ≥ 40：本玩家所有干员额外独立尝试一次，成功获得 15 技力
```

成员在 40 层后会分别掷两次，可以同次技能结束获得 `12+15=27` 技力；非成员只尝试 15 技力的一次。理论期望：成员 `12p + 15p·[L≥40]`，非成员 `15p·[L≥40]`；实际还受技能技力存储上限约束。229 层起 `p=100%`。死亡造成的技能结束不触发。实现：`addon/battle.js / procChance`、`install`。

### 灵巧 `skillfulShip`：2 人

```text
光环攻击速度加成 = 10 + L
L < 40：成员自身及上下左右 4 格
L ≥ 40：成员自身及周围 8 格
```

同一干员同时处于多个灵巧光环，只获得一次此加成。被击倒成员在倒地位置继续向邻格提供光环；撤退、强制离场不提供。最终攻速仍封顶 600。实现：`addon/battle.js / applyPassives`、`updateAura`。

### 奥术 `arcaneShip`：2 / 3 人

```text
成员造成法术伤害后，目标后续承受法术伤害倍率 M(L) = 1.20 + 0.01L
三人且施加时目标生命比例 < 50%：M低血(L) = 1.40 × (1.20 + 0.01L)
                                                        = 1.68 + 0.014L
持续时间 = 3 秒
```

低血条件在施加时检查，严格小于 50%。同一敌人只保留一份最强奥术效果，包括共享战场的不同玩家；不同成员施加的奥术不能连乘。该效果在法术伤害完成后施加，触发本身的那一击不追溯获得新倍率。实现：`addon/battle.js / applyPassives`、`install` 中的 `damaged` 钩子。

### 坚守 `steadShip`：2 / 3 人

```text
本玩家所有干员生命值加成 = 0.25 + 0.012L
单项最大生命值倍率 M(L) = 1.25 + 0.012L
三人时非成员所受伤害保留 60%，其余 40% 分摊给在场成员
每个成员分摊的原始真伤 = 未转移前已减免伤害 × 0.40 / 在场坚守成员数
成员受击反伤的原始法术伤害 D(L) = 850 + 10L
每名成员反伤冷却 = 0.2 秒
反伤后敌人脆弱：承受伤害倍率 1.40，持续 5 秒
```

分摊值随后仍经过承受者的真伤结算、护盾等流程。反伤无来源，不吃该成员的伤害增幅；归属仍记给被攻击成员。生命流失不触发反伤，反伤和分摊不会相互递归触发。实现：`addon/battle.js / applyPassives`、`install` 中的分摊与反伤钩子。

### 助力 `deputShip`：2 / 3 人

```text
本玩家所有干员防御加成 = 0.15 + 0.012L
单项防御倍率 M(L) = 1.15 + 0.012L
再部署时间倍率 = 0.70
每次休整期结束：所有当前已激活盟约 ΔL = (助力档位 ≥ 2 ? 4 : 2)
```

两人档至少需要 2 名不同干员；三人高档允许同名普通与精锐作为不同状态计数。助力也会给自身加层，单次 `+2/+4` 不再乘自身层数。实现：`addon/battle.js / applyPassives`，`addon/meta.js / registerMeta`。

### 远见 `visiShip`：场上加整备区 2 人

```text
累计资金里程碑奖励 F(L) = 2 × floor(L / 10)
本次资金奖励 = 2 × [floor(L / 10) - 已支付里程碑数]
首次激活且 L ≥ 80：远见干员购买价格永久 -1
首次激活且 L ≥ 150：全部干员购买价格永久 -1
价格结果 = max(0, 其他价格调整后的价格 - 适用折扣)
```

150 层档扩大适用范围，不会在 80 层的基础上再减一次。折扣一旦解锁永久保留；里程碑只支付新增部分，休整期已结束时获得的资金延后到下回合，避免被剩余资金清零吞掉。实现：`addon/meta.js / settleCoins`、`latchVisiDiscount`。

### 奇迹 `miraShip`：场上加整备区 2 人

```text
手动刷新后、下次刷新免费概率 p(L) = clamp(0.18 + 0.003L, 0, 1)
累计资金里程碑奖励 F(L) = 20 × floor(L / 100)
本次资金奖励 = 20 × [floor(L / 100) - 已支付里程碑数]
```

已有免费刷新次数时不再进行这次概率尝试；重触发的刷新不作为手动刷新。274 层起免费概率达到 100%。黑板 `probk=0.3` 在当前实现中没有参与公式，不应额外乘入。实现：`addon/meta.js / registerMeta`、`settleCoins`。

### 投资人 `investShip`：场上加整备区 3 人

```text
获得时特质触发次数 R(L) = 2，L < 100
                        = 3，L ≥ 100
未激活投资人时 R = 1
无其他约束时，一次“获得时 +n 层”的累计增量 = R(L) × n
```

这是“获得时特质”重复执行，不是所有叠层、技能或战斗事件统一乘 2/3；如果特质内部有一次性判断、数量限制或盟约达到 999 层，应按每次实际执行结算。实现：`effectsMeta.js / investRepeat`。

### 突袭 `raidShip`：2 人

```text
成功突袭再部署后，成员攻击力及生命值加成 = 0.25 + 0.01L
两种单项属性倍率 M(L) = 1.25 + 0.01L
L ≥ 50：本玩家所有干员攻击速度 +50
```

属性加成由成功突袭再部署获得，持续到离场；不是开战立即无条件获得。技能就绪或停攻达到 10 秒、当前攻击范围无敌人且有有效落点时尝试突袭，保留技力免费再部署。层数不改变 10 秒停攻阈值。实现：`addon/battle.js / raidMods`、`raidPoll`、`raidRedeploy`。

### 不屈 `indomShip`：2 / 3 人

```text
地面位置干员立即免费再部署概率 p(L) = clamp(0.18 + 0.004L, 0, 1)
三人时地面干员被击倒：场上所有本玩家干员 +5 技力
```

205 层起概率达到 100%。概率会在被击倒、正常撤退、行商撤退及傀儡师切换时尝试；傀儡师切换成功会把免费立即部署资格留给下一次离场。三人 `+5` 技力只在被击倒时触发。此处“地面”按干员近战位置判定，不按当前所在格是否为地面。实现：`addon/battle.js / procChance`、`install`。

### 调和 `maniShip`：1 人

```text
已有至少 1 名真实场上成员的核心盟约有效人数 = 原有效人数 + 1
调和干员享受所有已激活核心盟约效果
以上增益与 L 无关
```

不同调和成员不会重复给同一核心盟约 `+1`，也不会把完全没有真实成员的核心盟约凭空激活。`noStack=true` 只隐藏层数，不禁止存储与累加层数。实现：`bondsMeta.js / computeBonds`，`support/index.js / isMember`。

### 协防干员 `emptyShip`：2 人

```text
本玩家所有干员承受物理、法术伤害倍率 = 0.80
普通协防成员造成伤害倍率 = 1.20
精锐协防成员造成伤害倍率 = 1.40
以上增益与 L 无关
```

承受真伤不使用这里的物理、法术减伤倍率。非协防成员只有全体减伤，不获得成员增伤。`noStack=true`，内部层数仍可增加。实现：`addon/battle.js / applyStatic`。

### 独行 `soloShip`：恰好 1 名不同独行干员

```text
成员攻击力百分比加成 = 0.60，单项攻击力倍率 = 1.60
成员生命值百分比加成 = 0.60，单项生命值倍率 = 1.60
每次部署获得技力 = 15
以上增益与 L 无关
```

同名多份干员仍算一个名字，可同时受益；出现第 2 名不同独行干员才关闭盟约。`noStack=true`，内部层数仍可增加。实现：`bondsMeta.js / tierFor`，`addon/battle.js / applyStatic`、`install`。

### 绝技 `suntShip`：场上 2 / 5 名精锐

```text
本玩家精锐干员攻击力百分比加成 = 0.30，单项攻击力倍率 = 1.30
五精锐时精锐干员及其召唤物的技力消耗倍率 = 0.70
只有绝技调整时：最终技力消耗 = max(0, floor(基础技力消耗 × 0.70))
存在其他调整时：最终技力消耗 = max(0, floor(基础技力消耗 × Π技力消耗倍率 + 技力消耗固定加算))
以上增益与 L 无关
```

统计全部精锐干员，不要求这些干员自身携带绝技盟约；同名精锐重复计数。普通干员不获得攻击力增益。`noStack=true`，内部层数仍可增加。实现：`addon/battle.js / applyStatic`、`suntSpCost`，`skills.js / spCost`。
