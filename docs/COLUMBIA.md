# 哥伦比亚盟约实现说明

当前实现以《哥伦比亚 (1).docx》的干员设计为准。星极的休整特质按已确认口径处理：普通哥伦比亚 +4、灵巧 +3，精锐分别 +8、+6。多萝西保留五阶／六阶外援配置、原有技能和召唤物，仅将盟约归属调整为哥伦比亚，不迁入常规池。

|---|---|---|---|

石英、星源、响石、星极新增独立技能文件，提供全部可选技能、天赋和当前模组效果。霍尔海雅、谬因复用原有完整技能实现，分别迁入四阶、六阶常规卡池，不再占用外援选择名额。训练状态、技能等级、潜能和模组等级沿用同阶棋子的构建规则。其余哥伦比亚外援不在本次迁池范围。

数据源是原始游戏表；隐藏资料库只提供来源记录和已经归档的图片、模型。`tools/build-data.mjs` 先构建角色表单，再由 `tools/columbia-roster-data.mjs` 生成常规棋子，最后应用盟约和特质。生成的 JSON 不单独维护。

## 双星

双星是星极、星源和溯光星源的干员特性，显示在干员特质说明中，不作为盟约出现，不参与人数、层数或随机禁用统计。同一玩家场上同时存在星极与至少一名星源时产生联动；星源和溯光星源两人不能代替星极。

在场成员通过装备的可撤销 grant 共享装备效果，不复制装备实体、不改变装备归属，同一装备 ID 不重复授予已有佩戴者。离场时撤销共享效果。科技装备仅能配发给哥伦比亚干员，浏览器拖放预校验、服务器配发和战斗效果安装均检查此限制。被拒绝的配发不移走手中装备，也不替换或销毁目标原装备；六人档的 50 攻速每位佩戴者只加一次。

相交判断使用各自当前的原生攻击范围，包括正在生效的技能范围和攻击距离。星极与星源的范围相交时，两者都能选中对方范围内的目标；技能自动触发也读取延伸范围。共享范围不递归扩大。离场、移动、技能切换后更新，且不覆盖其他效果添加的范围。

## 科技装备

三名不同哥伦比亚干员激活第一档；跨过每个 50 层里程碑发放一件不重复装备，最多六件。每位玩家使用独立随机流。整备区满而发放失败时不消耗装备种类名额，下一次跨越里程碑再尝试。

六名不同成员激活第二档。项目的 `tier` 表示达到的档数，故三人档为 `tier=1`、六人档为 `tier=2`，不能直接按人数比较。

| 装备 | 普通 → 过载 |
|---|---|
| 拓荒者蓄力装具 | 初始 115% → 130% 伤害；每三次攻击 +1% → +2%；上限 200% → 300% |
| 梅兰德战地保单 | 实际伤害的 15% → 30% 治疗最低生命比例成员；削攻 2% → 4%，持续 15 → 30 秒，最多 15 层 |
| 过载护盾 | 生命 +2000 → +4000，双抗增加最大生命的 0.6% → 1.2%；首次跌破半血锁血 6 → 12 秒 |
| 灰质引擎 | 攻击 +45% → +90%；每 1000 实际伤害再 +1% → +2%，最多 100 层；攻击附带 5% → 10% 神经损伤 |
| 多维尔综合诊疗仪 | 治疗 +20% → +40%；实际治疗后自身四邻格技力 +1 → +2，目标四邻格治疗 15% → 30%，扩散不递归触发自身 |
| 反重力投送场 | 开技能时浮空 2 → 4 秒，同一格五秒冷却；技能中范围内成员技力回复 +0.25 → +0.5、攻速 +40 → +80 |

护盾锁血采用工作区 Markdown 已调整的 6／12 秒，优先于 Word 中的旧值 7／14 秒。六件装备的战斗效果通过现有装备 Scope 安装与清理，治疗、伤害、控制、技力、锁血均走现有模拟接口。
