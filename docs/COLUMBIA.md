# 哥伦比亚盟约 v1.2

三名不同哥伦比亚干员在场时，装备效果初始提升50%，每层再提升0.3%，即每100层再提升30%。六名不同成员在场时，激活哥伦比亚科技装备的专属效果。原有六人装备共享已移除，双星的装备借用保留。

## 装备获取

达到20、50、100、170、250、350层时，各获得一次装备领取机会。只有在三人档已激活且玩家可以操作的休整期，才会出现装备选择。战斗中、战斗结算或休整期结束时达到门槛，留到下一休整期开放；先叠层后激活也会补齐领取机会。

每次随机提供两件尚未领取过的科技装备，从中选择一件。多次领取不重复，最后只剩一种时直接领取。不进入商店，不可合并，只能配发给哥伦比亚干员。一次跨过多个门槛时依次选择，未领取的候选保持不变并跨休整期保留，销毁已领取的装备不返还领取次数。整备区满而无法领取时保留候选与次数；最后一件自动发放时若两个整备区均满，也保留到腾出空间后再发。

装备抽选使用每名玩家独立的随机流，复用现有装备奖励队列、二选一界面及领取指令。

## 科技装备

基础效果无需六人档即可生效；三人档激活后，正面属性和效果系数享受装备增幅。六人档专属效果要求同一玩家有六名不同哥伦比亚成员实际在场，成员离场导致不足六名时停止生效。

| 装备 | 基础效果 | 六人档专属效果 |
|---|---|---|
| 拓荒者蓄力装具 | 携带者基础攻击力+300；周围四格己方干员基础攻击力+150 | 攻击初始造成115%伤害，每三次攻击增加1个百分点，最高200%；装备增幅只放大超过100%的部分 |
| 梅兰德战地保单 | 携带者攻速+50、基础攻击力+200 | 按实际伤害的15%治疗己方生命百分比最低的干员 |
| 过载护盾 | 携带者阻挡数+3、生命值+2000；周围八格己方干员生命值+500 | 防御力、法术抗性各增加最大生命值的0.6%，本装备提供的法抗最多+30 |
| 灰质引擎 | 攻击力+45%；额外获得上下左右四格己方干员攻击力总和的30%，不含自身 | 每造成1000点实际伤害，攻击力再+1%，最多100层；攻击附带实际伤害5%的神经损伤 |
| 多维尔综合诊疗仪 | 治疗效果+50%；每次治疗人数+1 | 每次实际治疗为携带者周围四格己方干员提供1点技力，并为治疗目标周围四格己方干员回复本次治疗量的15%；扩散不递归触发 |
| 反重力投送场 | 携带者技能持续时间+50%、技力回复+0.25/秒 | 技能期间，攻击范围内己方干员技力回复+0.25/秒、攻速+40 |

表中均为未计算三人档增幅的数值。治疗人数固定只增加一人，不随三人档增幅扩大，也不增加攻击目标数。攻击力平加计入百分比加成之前；灰质引擎借来的攻击作为最终加算，不重复借用其他引擎已借来的攻击，避免相邻引擎形成递归增长。

基础光环只影响同一玩家对应邻格的在场干员，随携带者与目标的移动、离场更新。灰质引擎的伤害进度在六人条件暂时失效时保留，失效期间不累计伤害叠攻；恢复六人条件后继续使用已有进度。生命、治疗、伤害与技力仍走现有模拟接口，装备卸除或双星借用结束时统一清理效果。

## 双星与数据维护

双星属于星极、星源、溯光星源的干员特性，不作为独立盟约，也不参与禁用统计。同一玩家的星极与至少一名星源或溯光星源同时在场时借用彼此的完整装备效果；两个星源不能替代星极。借用不复制装备实体，不改变装备归属，科技装备的六人档部分仍受六人条件约束。

攻击范围相交时，双方可选中对方范围内的目标，自动技能策略也读取延伸范围；范围不递归扩大。离场、移动、技能切换后更新，不覆盖其他来源的额外范围。

数值维护在 shared/columbia.js，装备和盟约数据由 tools/columbia-data.mjs 生成，常规成员由 tools/columbia-roster-data.mjs 生成。运行 node tools/build-data.mjs --offline --quiet 更新运行时 JSON，不单独修改生成结果。素材仍使用原有公开素材下载流程。

v1.2 已按功能分支合入 develop、发现问题后在 bugfix 分支修复并合回 develop 的顺序完成验收。最终完整测试集合6393项通过、0失败、98项跳过；其中两项性能用例另行独立运行并通过，三项哥伦比亚浏览器用例也已单独运行通过。210个完整黄金场景与更新后的基线一致，场景中没有内容错误。

整局回归先以 MATCH_SEEDS=20 完成单人四难度和五组多人配置的180局检查，均以零错误结束；最终完整测试集合复测采用 MATCH_SEEDS=1 确认修复后的接口。性能单独测量，普通70敌人波次约0.055毫秒/帧，压力场景约0.088毫秒/帧，均低于0.5毫秒门槛。真实浏览器额外覆盖连续五次二选一、不重复领取、稍后恢复候选、最后一种自动领取，以及保留至后续休整期的提示。
