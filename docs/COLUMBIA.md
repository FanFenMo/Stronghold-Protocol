# 哥伦比亚盟约实现说明

当前实现为哥伦比亚 v1.1。三名不同成员激活装备成长，零层额外增幅为50%，每层再增加0.3%，即每100层再提升30%。六名不同成员激活装备共享，每名在场成员获得可共享装备总加成的20%，不除以人数。多萝西保留五阶／六阶外援配置，不迁入常规池。

石英、星源、响石、星极新增独立技能文件，提供全部可选技能、天赋和当前模组效果。霍尔海雅、谬因复用原有完整技能实现，分别迁入四阶、六阶常规卡池，不再占用外援选择名额。训练状态、技能等级、潜能和模组等级沿用同阶棋子的构建规则。其余哥伦比亚外援不在本次迁池范围。

数据源是原始游戏表；隐藏资料库只提供来源记录和已经归档的图片、模型。`tools/build-data.mjs` 先构建角色表单，再由 `tools/columbia-roster-data.mjs` 生成常规棋子，最后应用盟约和特质。生成的 JSON 不单独维护。

## 双星

双星是星极、星源和溯光星源的干员特性，显示在干员特质说明中，不作为盟约出现，不参与人数、层数或随机禁用统计。同一玩家场上同时存在星极与至少一名星源时产生联动；星源和溯光星源两人不能代替星极。

双星通过装备的可撤销 grant 借用完整效果，不复制装备实体、不改变装备归属，同一装备 ID 不重复授予已有佩戴者。离场时撤销借用。双星保留科技装备借用，与六人共享独立叠加，借来的效果不再进入六人共享池。科技装备仅能配发给哥伦比亚干员，浏览器拖放、服务器配发和战斗安装均检查限制。旧六人档额外50攻速已删除。

相交判断使用各自当前的原生攻击范围，包括正在生效的技能范围和攻击距离。星极与星源的范围相交时，两者都能选中对方范围内的目标；技能自动触发也读取延伸范围。共享范围不递归扩大。离场、移动、技能切换后更新，且不覆盖其他效果添加的范围。

## 装备成长与共享

层数增幅只放大装备的正面战斗属性与指定效果系数；伤害或治疗倍率只放大超过100%的部分。资金、获得干员数量、复活次数、范围、触发间隔、叠层上限、负面代价不随层数成长。战斗内层数改变会更新已有加成，不重置叠层进度。

六人共享只汇总同一玩家在场哥伦比亚干员实际佩戴的白名单装备；先计算携带者当前有效加成，再向每名成员各授予总和的20%。自身装备、双星借用与共享叠加。成员离场后移除其贡献与接收效果，低于六名不同成员时撤销六人共享。

可共享装备为维式重锤、坚守盾牌、源石溶剂、战栗维式重锤、萨尔贡浓茶、叙拉古正装、精准狙击镜、炎国短刀、迅捷作战粮、歌利亚头盔、阿戈尔重刃、奥术法阵、坚固维式重锤、加速维式重锤、有限加速器、休眠子裔、灼燃维式重锤、催泪瓦斯、谢拉格不融冰、双模机械臂、天马之盔、天马之枪。其他装备、所有盟约专属装备及法术道具均不进入六人共享池。

战栗、沉默、锁血、灼燃损伤、弱点伤害转换和天马套装效果不共享。叙拉古正装只共享自身攻速，原有两侧光环保留；精准狙击镜保留距离条件；歌利亚头盔按原携带者的条件结算。有限加速器只共享实际已叠攻速，比例额外减半至10%，上限仍60层。阿戈尔重刃每件共享效果的攻速代价固定-10。护盾无人机的抵挡伤害效果不共享。

源石溶剂的六人共享代价为每名成员每秒受到30点持续环境真实伤害，取代携带者原有周期伤害；多件溶剂不重复施加共享代价。未达到共享条件时保留原装备代价。催泪瓦斯与谢拉格不融冰共享触发概率，控制效果与寒冷时长保持原规则。

## 科技装备

三名不同哥伦比亚干员激活第一档；跨过每个 30 层里程碑发放一件不重复装备，最多六件，180层发满。每位玩家使用独立随机流。整备区满而发放失败时不消耗装备种类名额，下一次跨越里程碑再尝试。

六名不同成员激活第二档。项目的 `tier` 表示达到的档数，故三人档为 `tier=1`、六人档为 `tier=2`，不能直接按人数比较。

科技装备不进入六人共享池，仍享受三人层数成长。旧过载已移除。

| 装备 | 基础效果 |
|---|---|
| 拓荒者蓄力装具 | 初始115%伤害，每三次攻击增加1个百分点，最高200%；层数只放大超过100%的部分 |
| 梅兰德战地保单 | 实际伤害的15%治疗最低生命比例成员；削攻删除 |
| 过载护盾 | 生命+2000，防御和法抗增加最大生命的0.6%；装备法抗加成最多+30，锁血删除 |
| 灰质引擎 | 攻击+45%，每1000实际伤害再+1%，最多100层；攻击附带5%神经损伤 |
| 多维尔综合诊疗仪 | 治疗+20%；实际治疗后自身四邻格技力+1，目标四邻格治疗15%，扩散不递归触发自身 |
| 反重力投送场 | 技能中范围内成员技力回复+0.25/秒、攻速+40；浮空删除 |

六件装备通过现有装备Scope安装与清理，生命、治疗、伤害、技力均走现有模拟接口。因为科技装备整体退出共享池，旧讨论中的科技共享比例、灰质共享上限和反重力共享减半规则不再适用。
