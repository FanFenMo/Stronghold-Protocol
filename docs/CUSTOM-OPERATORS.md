# 外援干员与服务器部署

`main` 是可运行版本的发布分支，包含火陈剑气边界修复、原九名外援、网页配置、玛恩纳的卡西米尔技力特性和阿戈尔 v1.3 吞噬链攻击传递。外援功能开发分支为 `feature/support-operators`，火陈修复另有独立分支 `bugfix/chen3-sword-wave-boundaries`。本次上游选择性整合在 `feature/upstream-selected-updates` 开发并合入 `main` 发布。干员沿用项目的内容注册、浏览器／服务器共用战斗引擎、技能调配和素材下载流程；每名干员均有普通和精锐版本，三个技能可选，技能按原项目策略自动释放。

在大厅或本局信息确认阶段打开「干员调配 → 外援干员」，为五本、六本各添加最多两名外援。同一干员不能重复添加或同时占据两档，整合分支将候选扩展到 73 名，均可放在任一档。配置保存在当前玩家的浏览器中，并随该玩家进入房间。确认本局信息后锁定，本局商店、奖励和盟约人员只纳入自己选中的外援；其他玩家的外援不会进入自己的卡池。未选外援的默认卡池保持原有 112 名干员。

数值、技能描述、天赋及攻击范围采用游戏公开数据表，技能效果对照 PRTS 核实。沿用项目的普通版技能等级四、精锐版技能等级七；普通／精锐采用精二一级／精二六十级，调配中可选择潜能 1～6 和练度档位，默认满潜、精二六十级练度加成。原九名保留上述指定盟约和默认技能／模组，其他候选沿用上游盟约。五本普通卡池库存八名，六本五名，三合一晋升精锐，选择档位不改变角色技能数值。

火陈技能三的剑气沿当前方向直行，碰到墙体、不可通行地块、动态障碍或战场边界时向右转，覆盖下侧边界和联防、首领场地，不会飞出地图。予愿安洁莉娜实现起飞、浮空／缚地、重量降低、对空阻挡与弹药攻击；望实现棋子相连激活、连线增伤及无视法抗、三种棋子伤害和弹药返还。望适配本项目自动作战：自动在范围内靠近敌人路线的位置放置棋子，整备区手动部署的棋子也加入同一网络。

克莱门莎实现物理攻击增伤、正面减伤、侵蚀损伤、放逐胶囊及侵蚀爆发联动轰炸。维什戴尔实现余震、残影爆炸、过载连射、六发弹药和魂灵之影；弹药打完后，最后一发的余震仍保留技能效果。魂灵之影部署按 PRTS 指定的距离最近、地图下方、地图左侧依次优先，独立于干员朝向。

酒神实现神经损伤、束缚增幅、诱导和持续伤害区域，以及能阻挡空中敌人的迷狂牢笼；牢笼只受到所阻挡敌人的攻击，三次后消失。真言实现麻痹触发元素伤害、麻痹保留概率、连锁攻击、技能期间的反隐和麻痹溢出伤害，复用原有麻痹中断攻击的事件流程。

玛恩纳普通和精锐版均新增特性：当前生效的卡西米尔每层增加 **0.005 点技力／秒**。基础自然回复为 1 点／秒，因此 100 层为 1.5、150 层为 1.75 点／秒。层数变化会立即更新，技能期间沿用原有自然回复暂停规则。该特性用已有盟约层数特质数据实现，独立于原来的部署后 100 秒属性加成。

干员本体的正、背面 Spine 沿用原有镜像。魂灵之影和本能的召唤使用同一镜像中现有皮肤模型。公开镜像缺少迷狂牢笼和望棋子的部分资源，它们使用项目原有渲染回退及角色特效，不影响阻挡、伤害和技能逻辑。

叙拉古使用上游 PRD：同一玩家成员共享尝试计数，名义长期触发率为 3%。第 n 次合格伤害的概率为 min(1, C × n)，C≈0.00138617772；首击约 0.1386%，未触发时递增，触发后重置。原有隐匿及结束后十秒的触发窗口、伤害资格和排除规则保持一致。

删除上游新增的顶部盟约栏“本局禁用”低亮圆盘及对应视图字段，并从模式禁用名单移除独行。独行按原逻辑在场上一名独行干员时生效，两名不同独行干员时停止加成。本局信息仍保留其他实际模式限制的说明。

## 阿戈尔盟约调整 v1.3

调整分支为 `feature/aegir-covenant-adjustments-v1.3`，v1.2 已在同名旧分支完成并推送。幽灵鲨获得时使阿戈尔层数增加 2；战斗中自身每击倒 5 名敌人，使已激活阿戈尔增加 1 层，每回合上限 10 层。精锐获得时增加 4 层，每 5 次击杀增加 2 层，战斗上限 20 层。

归溟幽灵鲨获得时使阿戈尔增加 4 层、不屈增加 6 层。切换为替身时，按同一行在场干员数（含自身）每 2 人一组，向下取整，使已激活阿戈尔每组增加 1 层、不屈每组增加 2 层；精锐增加层数翻倍。回到本体、击杀敌人或替身被击倒不再触发此叠层。战斗特质沿用项目的个人战斗叠层范围，联防和首领场地不结算战斗叠层。

所有阿戈尔阵容的吞噬均不再叠加盟约层数，始终获得被吞噬者阻挡数。获得的基础攻击力占比为 `50% + 吞噬时阿戈尔层数 × 0.5%`，100、300、500 层分别为 100%、200%、300%，之后继续线性增长。攻击力仍为最终加算，技能百分比加攻不放大这部分。

五名不同阿戈尔取消真伤灼烧，改为阻挡目标攻击传递，保留原五人复活效果。吞噬者没有自身可攻击目标时，沿用自己的攻击间隔和普攻效果，攻击吞噬链中存活干员正在阻挡的非远程敌人。每次传递使防御、法抗结算后的最终伤害保留 80%，两次为 64%、三次为 51.2%。开战时记录的吞噬链不因中间干员死亡或移动而切断、缩短；末端存活并阻挡即可，末端死亡或停止阻挡时停止提供该目标。击杀归属吞噬者，传递攻击仍使用原有攻击特效、技力与弹药流程。

克莱门莎策略每累计吞噬 10 名干员（不限盟约），下回合获得一名不高于当时调度中心等级的随机阿戈尔，余数与未发出的奖励保留。策略不再额外修改吞噬层数、阻挡或伤害公式。网页特质、盟约和策略说明与数据同时更新，盟约表面说明不附括号示例。

本次调整已合入 `main` 发布分支。服务器部署直接使用 `main`，Node 版本、依赖、素材来源和安装／启动步骤与下文相同。

## 部署

依赖版本、端口、素材镜像、可选客户端资源提取和服务部署方式均沿用原项目。`package.json` 与 `package-lock.json` 未改变；生产环境仍使用 Node.js 22／24。新增素材记录放在原有 `docs/research/07-assets.json` 中，由 `npm run setup` 补下载，已有素材会复用。无需上传本机 `.runtime`、`node_modules` 或缓存。

新服务器按原流程安装，只需取本 fork 的对应分支：

```bash
git clone --branch main https://github.com/FanFenMo/Stronghold-Protocol.git
cd Stronghold-Protocol
npm ci
npm run setup
npm start
```

在已有服务器目录升级时，先按既有服务管理方式停止游戏进程，保留 `public/assets/local/` 与 `data/local-assets.json`。原仓库部署可添加此 fork 为新的远端，然后切换分支：

```bash
git remote add custom https://github.com/FanFenMo/Stronghold-Protocol.git
git fetch custom main
git switch --track custom/main
npm ci
npm run setup
```

若已存在该分支，后续在该分支运行 `git pull --ff-only`、`npm ci`、`npm run setup`。素材清单 `data/assets.json` 由 setup 生成，更新前可按原部署文档还原这个生成文件以免拉取冲突。完成后用原来的 systemd、Docker 或启动脚本重启；对应配置、环境变量及反向代理示例仍见 [DEPLOY.md](DEPLOY.md)。重启会结束内存中的对局，浏览器刷新后开始新局。

F 盘本地启动仍可双击 `scripts/start-windows.bat`；脚本优先使用项目已有的 `.runtime/node/node.exe`，没有便携运行时则使用已安装的 Node。Linux 服务器使用系统 Node，运行方式与此前相同。

## 上游选择性整合

潜能与练度设置随玩家保存，并同时用于战斗、召唤物和数值展示；练度对攻击、防御和生命单独乘算。快捷键、文字大小、实际攻击范围、地形装置详情、本机战绩、桌面安装、关闭窗口后恢复和开局全员同意重刷已接入原有界面。恢复需要同一浏览器、服务器仍保留对局；服务器重启后内存对局无法恢复。

战斗模块同步上游修正的治疗／持续回血、范围技能触发、推拉、召唤物、增益叠加、传送门、火陈剑气与跨半场突袭，并使用共用确定性数学函数。叙拉古改为上游 PRD，阿戈尔 v1.3、个人外援池、玛恩纳 0.005 技力特性和独行生效条件保持本 fork 规则。未加入干员持有／替补、自选编队、语言或日语语音切换及新悬赏选择界面。
